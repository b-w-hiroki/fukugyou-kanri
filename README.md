# 副業管理ツール

副業の収支・案件・税務をひとまとめに管理するための、単一 HTML ファイルの Web アプリです（`index.html` のタイトル／ヘッダー表記に基づく）。

## できること

- **ダッシュボード**: 今月の収入・支出・純利益・利益率を表示。月別収支の棒グラフと、経費カテゴリ内訳のドーナツグラフ（Chart.js 使用）
- **登録・一覧**: 種別（収入／支出）・日付・内容／案件名・金額・カテゴリで取引を登録。月での絞り込み、削除、CSV ダウンロードに対応
- **年間レポート**: 対象年を選んで、月別収支サマリー（収入・支出・純利益・利益率）を確認

登録データはブラウザの `localStorage`（キー: `fukugyou`）に保存されます。

## 開き方

`index.html` をブラウザで開いてください。ビルドは不要です。

グラフ表示には CDN（jsDelivr）から Chart.js 4.4.0 を読み込むため、表示にはインターネット接続が必要です。

## テスト

セキュリティ・バックアップ回帰テストがあります。

- `security.test.js` — Node.js のテストランナーで実行するテスト（表示時の文字列の literal 扱い、CSV のクォート／数式無害化など）
- `browser.test.js` — Playwright（Chromium）で実際にブラウザ上で確認するテスト

CI: `.github/workflows/security-tests.yml` が `push` / `pull_request` で Node.js 22 を使って両テストを実行します。

ローカル実行の例（CI の手順に基づく）:

```sh
node --test security.test.js backup.test.js
npm install --no-save playwright
npx playwright install --with-deps chromium
node browser.test.js
```


## バックアップと復元

「登録・一覧」の「全件をJSONバックアップ」で、月フィルターに関係なく全取引を保存します。CSVは表計算向けで、復元には使用できません。JSONはこのアプリのバージョン1形式、10MiB以下に対応します。バックアップには取引の内容・案件名・金額を含むので、安全な場所に保管してください。外部サーバーへ送信する機能ではありません。

復元は現在の全データを置き換えます。先に現在のJSONを保存してください。形式・日付・整数の金額・重複IDを検証し、件数と置換を確認してから書き込みます。キャンセル・不正ファイル・容量不足では保存内容と画面内の取引を変更しません。別端末へ復元後、日付・内容・金額を照合してから元のデータを削除してください。

既存保存データが破損していた場合は追加・削除を止め、JSONバックアップから元の文字列を `fukugyou-recovery.json` として退避できます。この退避ファイルは通常の復元形式とは異なります。読み込み自体が拒否された場合はブラウザの保存設定を確認してください。

## 集計の範囲

年間収支は登録金額の集計です。源泉徴収・所得税・住民税や申告書は計算しません。以前の年間収入に一律20.21%を掛けた表示は、対象条件を反映できないため削除しました。必要な税務確認は取引の種類・支払条件・申告年度に応じて行ってください。未入金の債権や案件の進捗は、現時点では別管理です。
